# Centro Integrado de Fisioterapia

Landing page premium criada pelo Agent Nexus no padrão mínimo Replit-like.

## Stack

- Vite
- React
- TypeScript
- Framer Motion
- Lucide React
- Preview estático publicável em `public/index.html`

## Arquivos principais

- `src/pages/home.tsx`: página principal editável.
- `src/lib/business-data.ts`: dados, serviços, FAQ e ferramentas de pesquisa.
- `src/components/floating-whatsapp.tsx`: botão fixo de WhatsApp.
- `docs/research.md`: pesquisa externa preparada.
- `docs/delivery-checklist.md`: checklist de qualidade.
- `rodar-local.bat`: inicializador local para Windows.

## Rodar

```bash
npm install
npm run dev
```
